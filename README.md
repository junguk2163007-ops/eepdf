# 전기기사 매뉴얼 PDF 자료실

링크만 있으면 누구나 휴대폰으로 PDF 목록을 보고 바로 열람하는 사이트입니다.

## PDF 추가하는 법 (컴퓨터 설치 없이 웹에서만)
1. 이 저장소의 `pdfs` 폴더에서 PDF를 넣을 분류 폴더를 엽니다. (예: `pdfs/03_측정·점검`)
2. 오른쪽 위 **Add file → Upload files**를 누르고 PDF를 끌어다 놓습니다.
3. 아래쪽 **Commit changes**를 누릅니다.
4. 1~2분 뒤 사이트에 자동 반영됩니다. (진행 상황은 위쪽 **Actions** 탭에서 볼 수 있어요.)

- 새 분류가 필요하면 `pdfs` 폴더 안에 새 폴더를 만드세요. **Add file → Create new file**에서 이름칸에 `새분류/파일명.txt`처럼 입력하면 폴더가 생깁니다. PDF는 그 뒤에 올리면 됩니다.
- 폴더 이름 앞의 `01_` 같은 번호는 순서를 정하는 용도이고 화면에는 보이지 않습니다.
- 분류 폴더 안에 폴더를 한 단계 더 만들면 소분류가 됩니다.
- `pdfs` 바로 아래에 PDF를 두면 "기타" 분류로 들어갑니다.
- PDF를 지우거나 옮기려면 파일을 열고 오른쪽 위 `...` 메뉴를 사용하세요.

## 구성
- `index.html` 목록 / `viewer.html` PDF 열람 / `style.css` 디자인
- `build.py` pdfs 폴더를 읽어 `manifest.json`(목록)을 만드는 스크립트. 자동 배포가 매번 실행하므로 직접 돌릴 필요가 없습니다.
- `.github/workflows/deploy.yml` 자동 배포 설정
- `lib/` PDF.js (Apache-2.0)

주의: 이 저장소는 공개라서 올린 PDF는 누구나 볼 수 있습니다. 저작권이 있는 자료나 개인정보가 든 파일은 올리지 마세요.
